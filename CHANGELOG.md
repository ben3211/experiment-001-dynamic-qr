# Changelog

All notable changes to **AI Project Template** are documented here.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.1.0] - 2026-08-02

### Added

- **AI Engineering Best Practices** section in `DEVELOPMENT_GUIDELINES.md` — prompt versioning, cost tracking, output validation, provider abstraction, and modular prompts
- **AI Feature Completion Checklist** — prompt tested, output validated, cost reviewed, docs updated

---

## [1.0.0] - 2026-08-01

### Added

- `README.md` — template overview, philosophy, and usage
- `START_NEW_PROJECT.md` — end-to-end workflow from clone to first commit
- `DEVELOPMENT_GUIDELINES.md` — universal engineering rules (architecture, testing, git, logging, errors, etc.)
- `PROJECT_CONTEXT.md` — project identity and setup template
- `CURRENT_STATE.md` — live project status template
- `ROADMAP.md` — phased planning template
- `docs/ARCHITECTURE.md` — system design template
- `docs/DECISIONS.md` — architectural decision record (ADR) template
- `.env.example` — environment variable placeholder file
- `.gitignore` — safe defaults for secrets, dependencies, builds, and IDE artifacts
- `.cursor/rules/project-context.mdc` — Cursor rule to read core docs before significant work

### Notes

- Initial public release intended as a reusable GitHub template repository.
- No application code included — documentation and tooling only.
